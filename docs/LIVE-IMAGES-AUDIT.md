# Live image audit, 22 September 2026

Every image on the live Shopify listings (`herbase.earth/products.json`) was
pulled, read at full size, and sorted by one test: is there a health or
function claim anywhere in the pixels? If yes it stays out, however small the
line. The set lives in `assets/products/live/`, the side-by-side is
`compare/live-images.html`, and the wiring is `data/live-images.json`.
